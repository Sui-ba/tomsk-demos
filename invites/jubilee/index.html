Как всё начиналось

Семьдесят лет — в нескольких кадрах

  1. 1957

    Родился в Томске, в доме на Липовой улицеместо для фото из семейного альбома

  2. 1979

    Окончил институт и пришёл работать на заводместо для фото из семейного альбома

  3. 1982

    Свадьба с Валентиной Сергеевнойместо для фото из семейного альбома

  4. 1985

    Родился сын, а через три года — дочьместо для фото из семейного альбома

  5. 2010

    Появился первый внукместо для фото из семейного альбома

  6. 2027

    Семьдесят — и вся семья за одним столомместо для фото из семейного альбома

Согласие на обработку данных

Отправляя ответ, вы соглашаетесь на обработку персональных данных:

  • Кто собирает: организаторы праздника (в этом примере — вымышленные).

  • Как отозвать: написать организаторам — ответ удалят.
